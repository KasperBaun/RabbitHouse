# Skiffertag — oversigt

> Saddeltag 35°, kip langs husets dybde. Hver tagflade: **1500 mm skrå flade**
> fra spærende til kip, **3400 mm bred** (3000 hus + 2 × 200 gavludhæng).
> Reference: `guide-naturskifertag.md` — ved tvivl gælder guiden.
> Ingen tagrende/nedløb og ingen skiferkit i dette byggeri (fravalgt;
> undertaget + den lukkede gavlkant tager fygesne/slagregn).

## Sikkerhed (gælder alle skridt)

- Arbejd fra stillads/platform og fra lægterne — **betræd aldrig færdig dækning**.
- Støvmaske + briller ved skæring/hugning af sten.
- Sten løftes op i små bundter; sortér på jorden.
